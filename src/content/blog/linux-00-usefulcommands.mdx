## Watch which process is eating the network

`iftop` gives you a live, per-connection view of bandwidth, which is the
quickest way to answer "why is my upload saturated". It needs an interface name,
so list them first.

```sh
sudo apt install iftop

ip addr              # find the interface name — eth0, wlan0, proton0, ...
sudo iftop -i proton0
```

The interface matters more than it looks. If you are on a VPN, watching `eth0`
shows you encrypted tunnel traffic in one lump; watching the tunnel interface
(`proton0` here) shows you the actual destinations.

## Append an alias or variable to .bashrc

Editing `.bashrc` in an editor is fine, but appending from the shell is faster
and scripts cleanly. `source` reloads it so the change applies to the shell you
are already in, instead of only to the next one you open.

```sh
echo "alias arrrg='ls -lah --color=auto'" >> ~/.bashrc && source ~/.bashrc
echo "export SOMEVAR='somevalue'" >> ~/.bashrc && source ~/.bashrc
```

Use `>>` and not `>`. A single `>` truncates the file, and truncating `.bashrc`
is a bad afternoon.
