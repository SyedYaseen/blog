Coolify is a self-hosted Heroku — you point it at a git repo, it builds and
runs the container. An old laptop is close to ideal hardware for it: it has a
battery, so it rides out power cuts, and the fans are already loud enough that
you will notice if something goes wrong.

The install is one command. The hardening afterwards is the part worth reading,
because this machine is about to be reachable from outside your network.

## Install

Run as root:

```sh
sudo su
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | sudo bash
```

Coolify then serves its dashboard on port 8000. To expose the apps it deploys
without opening ports on your router, see
[serving apps through Cloudflare tunnels](/blog/selfhost-01-cloudflaretunnels).

## Create an admin user

Do not keep working as root. Make a user with sudo rights and use that:

```sh
sudo adduser myadmin
sudo usermod -aG sudo myadmin
```

Log in as the new user and confirm `sudo` works **before** you go on to disable
password login. Locking yourself out of a headless box is a trip to find a
monitor.

## Disable password authentication

Once your SSH key is on the machine ([how to get it
there](/blog/linux-01-sshkeys)), turn off passwords entirely. An
internet-facing box gets brute-forced within hours; keys make that pointless.

```sh
sudo nano /etc/ssh/sshd_config
```

```
PermitRootLogin prohibit-password
PasswordAuthentication no
PermitEmptyPasswords no
```

```sh
sudo systemctl restart ssh
```

Keep your current session open while you test a new one in another terminal. If
the key does not work you still have a way back in.

## Firewall

I skipped this on the first pass and it caused problems later, so it is worth
doing deliberately. Default-deny inbound, allow outbound:

```sh
sudo ufw reset
sudo ufw default deny incoming
sudo ufw default allow outgoing
```

Then open only SSH and the web ports:

```sh
sudo ufw allow OpenSSH
sudo ufw allow 80,443/tcp
```

`limit` rate-limits repeated SSH connection attempts from one address — cheap
protection against brute force:

```sh
sudo ufw limit OpenSSH
```

Enable and check:

```sh
sudo ufw enable
sudo ufw status verbose
```

You are looking for something like this:

```
Status: active
Logging: on (low)
Default: deny (incoming), allow (outgoing), deny (routed)
New profiles: skip

To                         Action      From
--                         ------      ----
22/tcp (OpenSSH)           LIMIT IN    Anywhere
80,443/tcp                 ALLOW IN    Anywhere
22/tcp (OpenSSH (v6))      LIMIT IN    Anywhere (v6)
80,443/tcp (v6)            ALLOW IN    Anywhere (v6)
```

Note what is *not* in that list: port 8000. The Coolify dashboard stays
reachable only from the local network, which is exactly where you want an admin
panel. Enable the firewall while you are still connected — `ufw` does not drop
established sessions, but it is worth knowing that before you find out.
